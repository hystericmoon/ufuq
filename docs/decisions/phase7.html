Phase 7: Media and Shelf, three calls

Since macOS 15.4, third-party apps can't read Now Playing directly, and macOS 26 moved the volume HUD. Those two facts change what Phase 7 can promise. Pick one option per section; the green border is my recommendation.

1 · Source: adapter + Spotify fallback (C)
2 · Open panel: small media tile beside Battery (B)
3 · Scope: Now Playing + Shelf now; HUD and clipboard after a Mac spike (B)

1. Where Now Playing comes from

Every source is undocumented, so the module must report "unavailable" when one breaks, not crash.

A · MediaRemote adapter

Risk: medium
  • Every player: Spotify, Music, browsers, podcasts
  • A bundled helper run through the system Perl, which Apple still allows; BSD-3 licence
  • Not confirmed on macOS 26; its own test command checks it at launch

B · AppleScript only

Risk: high
  • Spotify and Music.app only, no browsers
  • An Automation prompt per player
  • Music.app's track and position are reported broken on macOS 26

C · Adapter, Spotify fallback Recommended

Risk: low overall
  • Adapter first; if its self-test fails, Spotify via AppleScript
  • If both fail, the tile shows "Now Playing unavailable"
  • Settings shows which source is in use, like "Using gh (login)"

3. What Phase 7 ships

Replacing the HUD and clipboard history both depend on how macOS 26 behaves, and that can only be tested on your Mac.

A · Everything in the plan

Risk: high
  • Now Playing, Shelf + AirDrop, HUD replacement, clipboard history
  • The HUD needs Accessibility access to intercept the media keys; brightness uses private APIs
  • Clipboard history may trigger macOS's "paste from other apps" prompt every time it reads

B · Ship the safe half, test the rest Recommended

Risk: low
  • Phase 7: Now Playing + file Shelf with AirDrop
  • Phase 7b: a small debug build checks the HUD key interception and clipboard reads on your Mac, then we decide
  • Done-when becomes: Spotify and a browser show with controls; a file dropped on the shelf can be AirDropped

C · Now Playing only

Risk: low
  • Fastest
  • Shelf waits, though it carries little risk
